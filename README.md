# Изучение взаимосвязи кредитного и рыночного рисков (срочная структура процентных ставок)

Дипломная работа посвящена моделированию совместной динамики доходностей государственных облигаций США и кредитных спредов корпоративных облигаций инвестиционного рейтинга через копулы с переменными во времени параметрами.

---

## Ноутбуки

### research/initial_research.ipynb

Загрузка данных FRED по трём рядам: доходность 10-летних Treasuries (DGS10), спреды облигаций Aaa (AAA10Y) и Baa (BAA10Y) за период с 2000 по 2026 год. Проверяется нормальность распределения ежедневных изменений (тест Шапиро–Уилка отвергает нормальность для всех рядов), строятся Q-Q графики относительно нормального и t-распределения. Тест Льюнга–Бокса подтверждает наличие ARCH-эффектов, что обосновывает применение GARCH(1,1)-t модели.

### research/distribution_analysis.ipynb

Сравниваются три варианта инноваций GARCH(1,1): нормальное распределение, t-распределение Стьюдента и асимметричное t-распределение Джонса–Фэдди. По критерию BIC для DGS10 и AAA10Y выбирается t-распределение; BAA10Y исключается из дальнейшего анализа ввиду структурной сложности этого инструмента на нижней границе инвестиционного рейтинга. Приводятся итоговые параметры GARCH(1,1)-t для выбранной пары.

### research/copula_analysis.ipynb

Стандартизированные остатки GARCH-t трансформируются в равномерные псевдонаблюдения через Probability Integral Transform. Оцениваются две динамические копулы с корреляцией, подчиняющейся процессу ARMA(1,m): гауссова и t-копула. Для обеих копул подбирается оптимальный параметр лага m методом максимального правдоподобия, оптимальным оказывается m = 80.

### research/copula_comparison.ipynb

Проводится формальное сравнение двух копул: информационные критерии AIC и BIC однозначно выделяют t-копулу, тест отношения правдоподобий отвергает гауссову копулу с p-value ≈ 3.74e-25. Анализируется хвостовая зависимость: гауссова копула предсказывает нулевую вероятность совместных экстремальных событий, тогда как эмпирические данные согласуются с асимптотическим коэффициентом t-копулы λ ≈ 0.13. По всем рассмотренным критериям t-копула демонстрирует значительно лучшее качество описания структуры зависимости.

### research/covar_calculation.ipynb

На основе оценённой t-копулы вычисляются временные ряды VaR и CoVaR для кредитных спредов AAA, обусловленных экстремальными движениями доходностей Treasuries. Рассматриваются два перекрёстных сценария: рост спредов при падении доходностей (U|D) и падение спредов при росте доходностей (D|U). Статистическая значимость разницы между VaR и CoVaR проверяется с помощью циклического блочного бутстрап-теста Колмогорова–Смирнова.

### research/delta_covar_calculation.ipynb

Вводится метрика ΔCoVaR, изолирующая перетекающий риск из Treasury yields в кредитные спреды путём вычитания базового CoVaR из стрессового. Показывается, что ΔCoVaR допускает мультипликативную декомпозицию на фактор волатильности σ_t и чистый копульный фактор g(ρ_t): первый объясняет ~80% дисперсии метрики, второй — ~58%. В рамках out-of-sample эксперимента установлено, что g(ρ_t) статистически значимо предсказывает события совместного хвостового риска (AUC = 0.549, 95% CI: [0.519, 0.580]), тогда как модель на основе одного GARCH эквивалентна случайному классификатору.

### research/term_structure_copula.ipynb

Методология расширяется на многомерный случай: доходность корпоративных облигаций Baa (DBAA) моделируется совместно с полной кривой государственных Treasuries (7 точек: 1M–10Y). PCA сокращает кривую до трёх факторов (Level, Slope, Curvature), объясняющих 92% дисперсии; для каждого ряда подбирается GARCH(1,1)-t маргинал. Оценивается DCC(1,1) t-копула, на основе которой аналитически выводятся условные распределения изменения DBAA-доходности для шести сценариев движения кривой.

## Запуск ноутбуков

Проект управляется с помощью [uv](https://docs.astral.sh/uv/). Все ноутбуки загружают данные напрямую из FRED через `pandas-datareader`, поэтому потребуется подключение к интернету.

Клонировать репозиторий и перейти в его корень:

```bash
git clone https://github.com/princebelkovetz/credit-market-risk.git
cd Diploma
```

Создать виртуальное окружение и установить зависимости из lock-файла:

```bash
uv sync
```
